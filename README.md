# AI Gym Mirror — Mobile Web App

A real-time AI-powered gym exercise tracker that runs entirely in your browser.
Works on any Android or iOS device — no installation required.

## Features
- 🏋️ Full-body exercise detection (Push-ups, Squats, Deadlifts, Curls, Lunges + more)
- 🧘 Yoga Mode, ABS Mode, Cardio Mode
- 📊 Live skeleton overlay with joint tracking
- 🔁 Automatic rep counting
- 🗣️ Voice form corrections
- 📳 Haptic vibration feedback on each rep
- 📱 Installable as a native-looking app (PWA)

## How to Use
1. Open the app link in Chrome on your Android phone
2. Allow camera access when prompted
3. Tap **▶ START** to begin tracking
4. Select your mode: ALL / UPPER / LOWER / ABS / CARDIO / YOGA
5. To install as a native app: tap Chrome menu → **Add to Home Screen**

## Tech Stack
- MediaPipe Pose (JavaScript)
- Vanilla JS + CSS3
- Progressive Web App (PWA)
- No backend — runs 100% in-browser
